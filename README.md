### 🏥 Proyecto Principal: SALUZ

Plataforma modular desarrollada en **Laravel 12** para centralizar y modernizar la gestión operativa del hospital, reemplazando aplicaciones legadas en PHP puro por un sistema unificado y mantenible.

| Módulo | Tecnologías | Qué resuelve |
| :--- | :--- | :--- |
| **Modules/Workforce** | `Laravel Modules`, `SISA Catalogs` | Gestión completa del personal: legajos, regímenes estatutarios, licencias anuales/extraordinarias, cronograma de guardias y sincronización con nomencladores de **SISA (profesiones y especialidades)**. |
| **Modules/Architecture** | `Livewire`, `EAV Custom Fields` | Mapeo físico y funcional del hospital: sedes, pabellones, salas y camas, con soporte para agregar campos personalizados según el área. |
| **Modules/Patrimony** | `Livewire PowerGrid` | Inventario de equipamiento médico y bienes del hospital, registro de estado de conservación y trazabilidad de transferencias internas entre sectores. |
| **System & Firma Digital** | `OpenSSL`, `Spatie Permission`, `ActivityLog` | Emisión y firma electrónica de documentos oficiales en PDF/A con verificación pública mediante código QR, auditoría de cambios y validación de licencias offline. |
| **UI & Frontend** | `Flux UI`, `Livewire 3`, `Tiptap`, `Tailwind` | Interfaz reactiva y rápida sin recargar la página, pensada para que los médicos y administrativos trabajen ágilmente en puestos de guardia y oficinas. |
