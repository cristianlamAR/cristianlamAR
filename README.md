### 👨‍💻 Sobre mí & Terreno Asistencial

Llevo más de 4 años desarrollando software dentro del **HIGA Gral. San Martín de La Plata**. Centralizo los desarrollos para la División de Salud Digital en [**@DSD-HIGASM**](https://github.com/DSD-HIGASM), creando y manteniendo aplicaciones para puestos asistenciales de guardia, quirófanos, salas de internación y gestión administrativa.

Estar adentro del hospital me enseñó a diseñar sin burocracia abstracta: software ágil, tolerante a cortes de red y pensado para que el personal de guardia y consultorios no pierda un segundo lidiando con la pantalla.

### 🏥 Proyecto Central: Saluz

Plataforma concebida directamente desde la trinchera operativa del hospital. Nace con el propósito de jubilar al viejo *SEH* (soldado caído en batalla 🪖) y erradicar la dispersión de herramientas aisladas y planillas manuales, unificando la administración institucional bajo un ecosistema moderno y escalable.

La premisa de diseño de Saluz no es burocrática, sino operativa: interfaces de mínima fricción para que el personal de salud no luche contra el sistema, tolerancia activa a la inestabilidad de red dentro del predio, y una arquitectura desacoplada que permite integrar nuevas áreas hospitalarias a demanda sin comprometer el funcionamiento general.

### 🏥 Ecosistema Hospitalario ([@DSD-HIGASM](https://github.com/DSD-HIGASM))

> [!NOTE]
> **🖥️ miky7 (IoT & Pantallas de Guardia):**  
> Evolución de miky6 para el despliegue y control de pantallas llamadoras en salas de espera de guardia: instalador automático, panel web centralizado, API con comunicación cifrada con clave simétrica y sincronización en red mesh distribuida tolerante a cortes del enlace central.

| Sistema | Área Operativa | Descripción |
| :--- | :--- | :--- |
| **🛏️ GEOCamas** | Internación / Espacio | Relevamiento y mapeo espacial-físico de camas, salas y pabellones de todo el predio hospitalario. |
| **🔪 Quirófanos** | Área Quirúrgica | Programación de cirugías programadas y de urgencia, asignación de mesas quirúrgicas y partes de quirófano. |
| **📋 HSIControl** | Sistemas Centrales | Administración de usuarios, unidades jerárquicas y documentación de Historia de Salud Integrada (en integración con API de miky7). |
| **🔬 PatoLab** | Diagnóstico | Trazabilidad de muestras biológicas, protocolos y estudios histopatológicos para Anatomía Patológica y Laboratorio. |
| **🦴 Banco de Prótesis** | Traumatología / Auditoría | Auditoría de expedientes clínicos, control de stock y seguimiento de solicitudes de prótesis e implantes. |
| **💰 SAMO** | Facturación | Administración y facturación hospitalaria bajo régimen SAMO (recupero de costos ante obras sociales y prepagas). |
| **👨‍⚕️ Ingreso Residentes** | Docencia e Investigación | Recepción digital y circuito de validación de legajos de nuevos profesionales médicos ingresantes. |
| **📊 SiGeCa** | Estadística | Sistema histórico para el censo hospitalario diario y cálculo de porcentaje de ocupación en camas censables. |
| **🏷️ AI-Search-CIE-10** | Codificación Médica | Buscador optimizado y estructuración JSON del nomenclador oficial de diagnósticos médicos CIE-10. |
